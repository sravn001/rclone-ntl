# rclone-ntl

Personal rclone setup that lets the owner of this repository (GitHub user sravn001) access their own Google Drive from their own computers. It is not a public service and has no other users.

## Privacy policy

This app is used only by its owner, for the owner's own Google Drive.

It reads and writes Google Drive files solely to copy the owner's own data between the owner's own computers and storage.

No data is collected, stored elsewhere, shared, sold or sent to any third party. No analytics or tracking.

Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: open an issue in this repository.
